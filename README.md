# DSA Practice in Java

A structured collection of my Data Structures and Algorithms practice in Java.

This repository contains solutions to problems from LeetCode and other coding platforms, organized **by pattern** (not by data type) for consistent learning, problem-solving practice, and technical interview preparation. Following the [NeetCode 150](https://neetcode.io/roadmap) roadmap order.

## Structure

- `01_Arrays_Hashing/` -- arrays, hashmaps, hashsets
- `02_Two_Pointers/`
- `03_Sliding_Window/`
- `04_Stack/`
- `05_Binary_Search/`
- `06_Linked_List/`
- `07_Trees/`
- `08_Backtracking/`
- `09_Graphs/`
- `10_Dynamic_Programming/`
- `Patterns/` -- reusable template skeletons per technique, not solved problems
